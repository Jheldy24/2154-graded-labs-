# AIDA 2154 — Graded Labs

This private instructor repository contains the current graded-lab source packages for AIDA 2154.

Available package:

- `week-04/graded-lab-image-segmentation` — one Week 4 submission worth 5%: guided segmentation and morphology work (3%) plus an independent production extension (2%).
- `week-05/graded-lab-feature-matching` — one Week 5 submission worth 5%: guided ORB/BFMatcher work (3%) plus an independent matching extension (2%).

Students work in their assigned private repository. This repository is an instructor source repository; students must not push changes here.
